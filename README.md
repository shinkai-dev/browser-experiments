# browser-experiments

ブラウザ完結系の検証（HTML/JS）資材を格納している。

---

## 検証資材一覧

| 検証アプリケーション名 | 内容 |
|---|---|
| indexeddb-crud | IndexedDB の CRUD 操作とトランザクションをブラウザだけで検証するコード |
| indexeddb-form-autosave | IndexedDB を利用して、フォームの入力内容をリアルタイムで自動保存（下書き保存）するコード |
| indexeddb-vector-search | IndexedDB とコサイン類似度計算を組み合わせて、ブラウザ上だけで動作する簡易的なベクトル検索（RAG）を検証するコード |
| web-locks-multi-instance | Web Locks API を利用して、ブラウザの多重起動（複数タブ・複数ウィンドウ）を検知・制御するコード |
