# File System Access API ローカル直接編集エディタ

## 概要
File System Access API を使ってローカルフォルダを直接開き、テキストファイル（`.txt` / `.md`）の
読み込み・編集・上書き保存・新規作成をブラウザだけで行うプロトタイプです。
OPFS などブラウザ内ストレージは経由せず、常にローカルファイルシステムを直接読み書きします。
サーバー・Node.js・外部ライブラリは使わず、HTML と JavaScript のみで完結しています。

検証したいポイント：
- ローカルフォルダ・ファイルへの読み書き権限（`queryPermission` / `requestPermission`）がどのタイミングで要求・確認されるか
- `createWritable()` によるローカルファイルへの直接上書き保存の挙動
- `getFileHandle(name, { create: true })` によるフォルダ内への新規ファイル作成の挙動

## 起動方法
File System Access API はセキュアコンテキストを前提としており、`file://` で直接開くと正しく動作しない場合があります。
**VS Code の Live Server 等でローカルサーバーを起動して開くことを推奨します。**

1. VS Code にこのフォルダを開く
2. 「Live Server」拡張機能をインストール
3. `index.html` を右クリック →「Open with Live Server」
4. `http://127.0.0.1:xxxx` でアクセス

## 動作確認環境
- Google Chrome または Microsoft Edge の最新版（Chromium系）を推奨
- Firefox / Safari は本記事執筆時点で `showDirectoryPicker` に対応していないため、警告メッセージが表示されます

## 検証できる操作・機能

| 操作 | 内容 |
|---|---|
| フォルダを開く | `showDirectoryPicker()` でローカルフォルダを選択し、直下の `.txt` / `.md` ファイルを一覧表示 |
| ファイルの選択・編集 | クリックしたファイルの内容を読み込み、テキストエリアで編集 |
| 新規ファイル作成 | ファイル名を入力して作成すると、開いているフォルダ内に空のファイルが作られ、そのままエディタで編集可能になる（拡張子未指定時は `.txt` を自動付与） |
| ローカルファイルへ上書き保存 | `createWritable()` を使い、初回はブラウザの許可ダイアログを経て readwrite 権限を取得したうえで保存 |
| ローカルファイルを再読込 | 未保存の編集内容を破棄し、ディスク上の最新内容を読み込み直す |

## 推奨する操作順
1. 「ローカルフォルダを選択」でテキストファイルを含む（または空の）フォルダを開く
2. 一覧からファイルを選んで内容を編集する、または「新規ファイル作成」でファイルを新しく作る
3. 「ローカルファイルへ上書き保存」を押し、初回に表示される権限ダイアログを確認する
4. 「ローカルファイルを再読込」で、保存内容がディスク上に正しく反映されているか確認する
5. 新規作成したファイルがフォルダの一覧（OSのファイラー等）にも実際に現れることを確認する

## DevTools での確認方法
- **Console**：`await dirHandle.queryPermission({ mode: 'readwrite' })` のような形で、現在の権限状態を直接確認できます（`app.state.dirHandle` はグローバルの `app` オブジェクトから参照可能）
- 権限ダイアログの挙動は、初回の保存・新規作成操作時にブラウザ標準の許可ポップアップが出るかどうかで確認してください
- OSのファイラーで開いたフォルダを表示しながら操作すると、保存・新規作成が即座にディスクへ反映される様子を直接確認できます
