# web-locks-multi-instance

Web Locks API を利用して、ブラウザの多重起動（複数タブ・複数ウィンドウ）を検知・制御するサンプルコードです。

サーバ・Node.js・外部ライブラリ不要で動作します。

---

## 動作確認環境

- Chrome / Edge（最新版）
- VS Code + Live Server 拡張機能

---

## 起動方法

1. VS Code で `web-locks-multi-instance/` フォルダを開く
2. `index.html` を右クリック →「Open with Live Server」
3. `http://localhost:5500` 等のローカル実行でブラウザが開く
4. **さらに別のタブやウィンドウで同じ URL を開く** と、多重起動検知が動作します。

> `index.html` をダブルクリックで直接開くと `file://` のセキュリティ制限でエラーになります。必ず Live Server 等のローカル実行で開いてください。
エラー気にしないのなら、ファイルを直接クリックしてください。

```
web-locks-multi-instance/
├── index.html   # UI（メイン画面 / 警告画面の切り替え）

└── README.md
```

---

## 検証できる挙動

1. **メインインスタンスの起動**: 最初に開いたタブがロックを取得し、メイン画面が表示されます。
2. **多重起動の検知**: すでにメインインスタンスが存在する状態で別タブを開くと、ロック取得に失敗し、警告画面に切り替わります。
3. **フォーカス通知**: 2つ目以降のタブを開こうとした際、`BroadcastChannel` を通じてメインインスタンス側に通知が飛び、コンソールにログが表示されます。
4. **ロックの解放**: メインインスタンスのタブを閉じるとロックが自動的に解放され、次に開くタブがメインインスタンスになれます。

---

## DevTools での確認方法

`F12 → Console`

- メインインスタンス側: `メインインスタンスとして起動しました。`
- 2つ目以降のタブ側: `既に他のプロセスで開かれています。`

また、`F12 → Application → Storage → Web Locks` で、現在保持されているロックの状態を確認できます。
